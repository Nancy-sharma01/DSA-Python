# Day 32 - Linked List Fundamentals (HackerRank)

## 🎯 Goal

Strengthen my understanding of Linked Lists by practicing the core operations on Hackerrank before moving back to more challenging LeetCode problems.

## ✅ Problems Solved

### 1. Print the Elements of a Linked List

* Learned how to traverse a linked list from the head to the end.
* Practiced using a pointer (`current`) and moving it with `current = current.next`.

### 2. Insert a Node at the Head

* Created a new node.
* Connected the new node to the existing head.
* Returned the new head of the linked list.
* Understood that no traversal is required for head insertion.

### 3. Insert a Node at the Tail

* Traversed the linked list to reach the last node.
* Created a new node and attached it to the end.
* Handled the edge case of an empty linked list.

## 📚 Key Concepts Learned

* Traversing a Singly Linked List
* Creating New Nodes
* Understanding `head` and `next` pointers
* Handling Empty Linked Lists
* Difference between Head Insertion and Tail Insertion
* Returning the Correct Head Reference

## 💡 Challenges Faced

Initially, I encountered runtime errors because I was:

* Treating node data as a node instead of creating a new node object.
* Forgetting to handle the empty linked list case.
* Using incorrect variable names (`head` vs. the function parameter).
* Missing the return statement in some cases.

Debugging these mistakes helped me understand how linked list pointers actually work.

## 🚀 Progress

Today was all about building a strong foundation. Rather than rushing into difficult problems, I focused on understanding the basics of linked list traversal and insertion. This practice has made me much more comfortable with pointer manipulation and prepared me for more advanced linked list problems.
